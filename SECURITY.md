# Security policy

## Reporting a vulnerability

Please don't report security problems in a public issue or pull request.

Use GitHub's private vulnerability reporting. Open the **Security** tab of this repository and choose **Report a vulnerability**. If you can't use that, email the maintainer at matthewallwood@protonmail.com.

Include:

- what you found and why it matters
- the steps to reproduce it
- the MintCare version (`mintcare --version`, or `./mintcare.py --version` from source) and your Linux Mint version

Remove personal details from logs and screenshots before you send them.

## Supported versions

Security fixes go into the latest release.

## After a report

The maintainer will confirm the report and work on a fix. Please keep the details private until a fix is released.
