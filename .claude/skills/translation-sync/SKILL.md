---
name: translation-sync
description: Bring the MintCare translations up to date after UI strings change - regenerate the template, merge, translate new entries into es, fr, de, pt and it, and validate.
---

Use this after changing any `_()`, `ngettext()` or `N_()` string in `mintcare/`.

1. Run `po/update-pot.sh`. This regenerates `po/mintcare.pot` and merges it into each `po/*.po`.
2. List the untranslated and fuzzy entries for each language: `msgattrib --untranslated --only-fuzzy po/<lang>.po`. Show the msgids so you can see what changed.
3. Translate each new entry. Keep every placeholder (`{0}`, `{1:.1f}`), keep the number and order of `%` signs, and keep markup such as `<b>` intact. Remove the `#, fuzzy` flag and any `#|` previous-text lines from entries you have translated.
4. Validate each catalogue with `msgfmt --check -o /dev/null po/<lang>.po`. It must report no errors.
5. Confirm zero untranslated and zero fuzzy entries in all five languages.
6. Run `./run-tests.sh`, which includes the translation checks.

Do not edit `locale/` or any `.mo` file. They are generated by `po/compile.sh`.
